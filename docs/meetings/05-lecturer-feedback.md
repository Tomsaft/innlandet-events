# Meeting 5: Feedback from the course lecturer

**Date:** 2026-10-20 | **Attendees:** [names, lecturer]

## Feedback
- The project was well received.
- It needs a stronger foundation: why is this app needed, and what is the
  problem statement?
- Statistics should carry the argument, for example how many people travel.
  This gives solid ground for presenting the idea.
- Start from the problem and work toward the solution, including how the
  information reaches the end user.
- Anyone should be able to check what is happening, including people outside
  the county.
- Consider the information flow between municipalities and the county.
- The lecturer's emphasis: the problem and the user side.

## Actions
- Write a problem statement backed by statistics (travel, and the foundation
  for the need)
- Define how information is delivered to the end user
- Look at how information flows between municipalities and the county

**Note:** The lecturer also encouraged aiming at the full scale, so the
long-term vision stays broad even if the first delivery is small.
